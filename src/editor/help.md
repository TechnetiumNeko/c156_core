# C156 Editor 使用说明

本页面为只读帮助文档。输入 `:q` 返回当前正在编辑的文档。

## 移动

- `h` / `j` / `k` / `l`：左、下、上、右移动；方向键也可使用。
- `<数字>h`、`<数字>j`、`<数字>k`、`<数字>l`：按指定次数移动。
- `gg`：移动到文档开头。
- `G`：移动到文档末尾；`<数字>G`：移动到指定行。
- `0` / `$`：移动到当前行开头 / 末尾。

## 编辑

- `i`：进入插入模式；按 `Esc` 返回普通模式。
- `o`：在当前行下方新建一行并进入插入模式。
- `dd`：删除当前行；`<数字>dd`：删除多行。
- 插入模式支持输入文字、换行、退格、Delete 和方向键。

## 命令

- `:wq`：保存文档并退出。
- `:q`：没有未保存修改时退出；有修改时提示先保存或使用 `:q!`。在帮助页中，`:q` 返回文档。
- `:q!`：放弃未保存修改并退出；在帮助页中，`:q!` 返回文档。
- `:h`：打开本帮助页。
- 其他 `:命令` 会交给 CLI 执行，例如 `:ls`、`:pwd`、`:cd <path>`。
