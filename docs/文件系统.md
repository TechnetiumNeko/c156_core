该网站以抽象文件系统组织内容。当前原型将其映射到真实文件系统，存储于 data 文件夹；这是存储实现，不规定网页或 CLI 必须采用文件命令作为接口。各层关系见[项目分层与入口](架构分层.md)。

data 文件夹下有如下子文件夹：

- main: 用户可树形访问的文件夹顶部，cli中的根目录。
- admin: 存储管理员可能访问修改的系统属性，例如用户列表和全局设置。
- resource：约定专门用于存储资源文件
- bin: 回收站

以下为待议项：

- profile: 用户个人主页
- template: 模板页面，用于编辑器创建新页面
- page: 其他需要特殊设计的页面，比如网站主页
