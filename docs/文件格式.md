虚拟文件系统中的文件共享同一抽象形态，并分为四类。下文的字段仅列出必要部分，实际开发中要根据需求不断新增字段。

AbstractFile 抽象文件
===============================
抽象文件由 sqlite 单文件容器实现，全部包含以下字段

- id: 一经生成不改变
- fullpath: 绝对路径
- kind: folder | document | executable | resource
- parent_id: 唯一的逻辑上级
- citation: 被引用关系表

抽象文件分为四类：

1.
Folder 文件夹
===============================

- file: 下级引用表
- defaultauthority: 下级文件继承的权限默认值

2.
Document 文字文档
===============================

- content: Markdown 格式的正文
- resource: 资源引用表
- authority: 权限数据
- 其他元数据

3.
Executable 程序文档S
===============================

用于制作一些复杂页面，访问时执行
理论上只有管理员能够上传

4.
Resource 资源
===============================
约定存储在 resource 文件夹

- content
- 其他元数据
