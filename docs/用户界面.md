# 当前用户界面

CLI 与 HTML／JS 工作台是开发验证和架构演示用的并列入口，都通过共用应用服务访问内容；当前两者最终都进入 `ContentService`，网页不执行 CLI 命令或启动终端编辑器。账号与授权由两种入口共享服务；后续实时协作也必须共享服务，不能在网页代码里复制一套权限或合并规则。详见[架构分层](架构分层.md)。

## CLI 与终端编辑器

使用自己的内容库时，先显式管理数据库，再启动 CLI：

```bash
python -m pip install -r requirements.txt
python -m src.storage migrate-legacy --source data --database data/c156.sqlite
python -m src.identity bootstrap-admin --database data/c156.sqlite --login-name owner --display-name 管理员
# 空新库：python -m src.storage init --database /path/to/new.sqlite
python run_cli.py --database data/c156.sqlite
# 等价入口：python -m src.cli --database data/c156.sqlite
```

默认路径为 `data/c156.sqlite`。缺失或未就绪库会给出管理命令提示，启动不自动创建、导入或修复；`--help` 不产生运行库。旧 `python -m src.file.bootstrap --database PATH` 已弃用，只转发显式 init。

CLI 的虚拟根为 main，各 CLI 实例独立保存 cwd。当前命令：

- `help [command]`、`exit`、`login`、`logout`
- `ls [path]`、`pwd`、`cd path`
- `tree [path] [-d max_depth]`、`cat path`
- `mkdir [--private] path`、`edit [--private] path`（--private 只在创建时使用）

路径支持 `.`, `..`, `~`，包含空格的参数使用引号。补全通过服务列目录。新增核心重命名、移动、软删除和 metadata 接口目前通过 Python API 使用，没有新增对应 CLI 命令。

`edit` 读取正文和基础 revision_id，编辑器返回后由 CLI 保存；无变化保存保留原换行和修订。冲突或存储失败保留 buffer 及原 revision_id，可继续编辑／查看或明确丢弃；不会静默覆盖并发成果。退出及取消同样保护未保存 buffer。整个编辑过程不占用数据库事务。

终端编辑器提供 Esc、h/j/k/l／箭头、带次数移动、G／gg、0／$、i／o、dd 和 `:wq`、`:q`、`:q!`、`:h`。`:q!` 明确请求丢弃；普通关闭不会把未保存内容作为主动丢弃。静态帮助不会成为虚拟内容文档。

## 浏览器工作台

快速试用可直接运行 `./start_demo.sh` 或 `python run_demo.py`，首次显式初始化新示例库，交互确认首管理员和隐藏密码，经正常登录播种后退出会话，再打开浏览器登录，后续保留已保存的修改。也可通过 `--no-browser` 只启动服务，或通过 `--port` 指定端口；停止时按 Ctrl+C。示例库为 `.c156/demo.sqlite`，与原始样本分开。

使用已有内容库：

```bash
python run_web.py --database data/c156.sqlite --port 8000
# 等价入口：python -m src.web --database data/c156.sqlite --port 8000
```

打开 <http://127.0.0.1:8000/>。指定相同的数据库即可与 CLI 访问同一 main 目录及内容；仅监听本地地址。

- 左侧展开目录、打开文档；在选中的目录中新建目录／文档。刷新只更新目录和路径，保留正在编辑的正文。
- 切换源码、预览或并排模式；窄屏切换编辑／阅读，目录可收起。
- 手动保存或 Ctrl／Cmd+S。预览随输入更新，输入本身不写入数据库。
- 未保存时切换文档可选择保存后切换、明确放弃或取消。保存失败取消切换；关闭／刷新页面由浏览器提示。草稿只在当前页面内存中。
- 冲突时保留原草稿，可查看最新正文、复制自己的草稿，或开始手动合并。合并从最新正文开始，同时保留原草稿供对照。尚未完成合并或保存时，关闭和切换同样提醒；不会直接覆盖别人修改。
- Markdown 支持标题、列表、引用、表格、链接及代码。预览净化 HTML，外部图片仅显示 alt 描述；LaTeX 与语法高亮尚未接入。

已提供用户登录、个人账号、站点账号与工作区访问管理；站点管理员和工作区 owner 是不同职责。私密范围由创建者及工作区 admin／owner 管理，仍须通过祖先阅读权限；冻结文档禁止其他人修改，管理角色不能静默绕过。账号激活／重置凭据只显示一次，应私下传递；密码不使用命令行参数。

会话失效保留原用户草稿与基础修订并暂停编辑；同用户重登可继续，换账号先处理旧草稿。CLI 在无内容权限时仍可 help／login／logout／exit。

目前没有 CRDT、分支切换、作品提交图、媒体上传、用户历史浏览或恢复界面。正文修订提供未来恢复基础；软删除不自动移动到 bin。未来 WebSocket 只作为实时协作传输层，房间授权、更新合并和持久化由后端协作服务完成。
