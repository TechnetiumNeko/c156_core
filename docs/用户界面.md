本页记录当前原型的 CLI 和终端编辑器，不是未来网页界面的设计。CLI 是便于开发和验证的入口；网页将作为独立入口访问共同的内容服务，不执行 CLI 命令。详见[项目分层与入口](架构分层.md)。

cli 部分会运行一个伪终端界面，可使用类似的通用命令进行路径操作。其根目录为 main.

- help [command]
- exit
- ls [path]
- pwd
- cd path
- tree [path] [-d max_depth]
- cat path
- mkdir path
- edit path

支持 ., .., ~

editor 部分会运行一个简化版的类 vim 编辑器，仅供测试使用。如果最终能在本地进行文档编辑，这是需要替换掉的:

- Esc
- h j k l 与箭头
- num h | j | k | l
- G gg
- 0 $
- i o
- dd
- :wq :q :h
