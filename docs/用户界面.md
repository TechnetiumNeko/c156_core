# 当前用户界面

CLI 是开发验证用的终端入口，网页尚未实现。CLI 和未来网页都通过共用 `ContentService` 访问内容；网页不执行 CLI 命令或启动终端编辑器。详见[架构分层](架构分层.md)。

先显式管理数据库，再启动 CLI：

```bash
python -m src.storage migrate-legacy --source data --database data/c156.sqlite
# 空新库：python -m src.storage init --database /path/to/new.sqlite
python run_cli.py --database data/c156.sqlite
# 等价入口：python -m src.cli --database data/c156.sqlite
```

默认路径为 `data/c156.sqlite`。缺失或未就绪库会给出管理命令提示，启动不自动创建、导入或修复；`--help` 不产生运行库。旧 `python -m src.file.bootstrap --database PATH` 已弃用，只转发显式 init。

CLI 的虚拟根为 main，各 CLI 实例独立保存 cwd。当前命令：

- `help [command]`、`exit`
- `ls [path]`、`pwd`、`cd path`
- `tree [path] [-d max_depth]`、`cat path`
- `mkdir path`、`edit path`

路径支持 `.`, `..`, `~`，包含空格的参数使用引号。补全通过服务列目录。新增核心重命名、移动、软删除和 metadata 接口目前通过 Python API 使用，没有新增对应 CLI 命令。

`edit` 读取正文和基础 revision_id，编辑器返回后由 CLI 保存；无变化保存保留原换行和修订。冲突或存储失败保留 buffer 及原 revision_id，可继续编辑／查看或明确丢弃；不会静默覆盖并发成果。退出及取消同样保护未保存 buffer。整个编辑过程不占用数据库事务。

终端编辑器提供 Esc、h/j/k/l／箭头、带次数移动、G／gg、0／$、i／o、dd 和 `:wq`、`:q`、`:q!`、`:h`。`:q!` 明确请求丢弃；普通关闭不会把未保存内容作为主动丢弃。静态帮助不会成为虚拟内容文档。

目前没有网页、用户权限、CRDT、分支切换、作品提交图、用户历史浏览或恢复界面。正文修订提供未来恢复基础；软删除不自动移动到 bin。
