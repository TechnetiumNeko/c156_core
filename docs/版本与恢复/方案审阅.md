# 方案审阅记录

[行为规范](行为规范.md)，[设计稿](P0-P1设计稿.md)

2026-10-08：按用户授权由独立 subagent 只读审阅设计与相关生产调用链。结论：总体可实施，无需改变已确认路线；实施前需要把以下边界明确成契约。

| 发现 | 当前证据 | 处理及规范定位 |
| --- | --- | --- |
| 回执不能冒充旧全文 Document | ContentService 保存返回 DocumentAccessView；EditorState.saveSucceeded 会重设基础 | 独立回执 + 动态 current_revision_id，W07/W09 |
| uncertainSave 未保存固定请求 | beginSave 重取当前 draft，失败仅布尔标志 | pending 独立且发送前持久化，W04/W08/L02 |
| 清稿后旧回调可能复活草稿 | 设计原先只称“代际”未规定删除后保留 | fencing token 空记录保留，L07 |
| 协议号不足以核验旧库 | Database 只看 user_version=2；verify_integrity 未核验触发器 | 固定结构核验 + 非2旧应用阻断，M02/M03 |
| SQLite 重建要保约束和事务 | revisions 自引用并被 entries 引用，存在不可变触发器 | 真实BEGIN、FK设置顺序和完整性验证，M04 |
| 原活动检查挡住已删除历史 | ContentOperations 及 ancestor_chain 拒绝 deleted 条目 | 专用 retained 历史路径 + 管理员列表，H07/L09 |
| 重放授权顺序不明确 | 旧保存路径始终要求 edit/unfrozen | 当前read后重放无正文结果；首次写检查完整能力，W06 |
| 退出/本机无权限出口需改调用链 | App 退出先discardWork；服务器读取失败无找回入口 | 排空本地写入、隐藏原账号、保留稿与受限出口，L04/L05 |

这些是审阅发现的实现风险，不代表已有新实现发生故障。计划和任务验收必须对应实际行为，不能只补一层响应 mock 或删除旧断言。

另在规划时发现 Bootstrap 尚无工作区/分支投影：已认证响应补充现有 scope 的两个 ID，匿名不暴露；已纳入规范 HTTP 契约。
