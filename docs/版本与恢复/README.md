## 怎样维护这些文档

- 现状附源码链接；建议说明理由和取舍；未决问题写清选择影响。
- 结论在用户确认后写入决策记录，议题页同步更新，不依赖聊天记录作为唯一依据。
- 不为每次讨论另建一份重复文档。直接更新对应议题，Git 保留修改历史。
- 一个议题足够明确后，将已确认行为整理为正式规格；本目录保留背景与链接，不维护另一套不同的实现契约。
- 验收描述用户可观察的行为。相关已有检查优先，新增测试只填具体覆盖缺口。
- 后续不逐条询问常规细节；直接完善整体方案，只集中提出影响架构、范围或用户行为的重要取舍。
