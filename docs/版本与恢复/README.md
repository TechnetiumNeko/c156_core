# P0 / P1 版本与恢复

当前分支已实现固定迁移链、历史授权与读取、保存/恢复回执、本机草稿协调及 Vue 接线。任务级检查和剩余限制见[执行记录](执行记录.md)；独立整分支总审阅和最终交付由控制器另行记录，不以本页宣告通过。

[行为规范](行为规范.md)是语义主入口，[实现与证据索引](行为规范.md#实现与证据索引)定位生产函数、行为测试与未验证项。[设计稿](P0-P1设计稿.md)和[决策记录](决策记录.md)保留已接受的边界和取舍，历史实施计划记录当时的任务要求。

| 议题 | 当前实现 |

P1 不含实时协作、分支创建、项目快照、恢复删除或草稿列表。真实 Docker 发布和原生浏览器故障尚未验证；本轮没有截图，未执行浏览器自动点击或表单测试。

后续改变行为时先定位规范语义 ID，再同步实现、相关已有测试及专题事实。常规实现细节无需重复确认，新的重要架构决策仍由用户选择。
