# 历史权限

[索引](README.md)，[行为规范 H01–H07](行为规范.md)，[决策记录](决策记录.md)

`history_read` 与普通 read 独立。editor 默认具备，reader 可单独获授或撤销；继承、私密、祖先可读和工作区成员规则仍由 AccessPolicy 每次判断。Vue 使用返回 actions 显示历史入口，不推断服务端权限。

历史沿请求 scope 的分支当前正文父链读取。分页固定开始时 head，游标绑定范围且不充当权限凭据。获权后可读获权前历史；移动后按当前策略判断，对象自身 private/ACL 保留。撤销 read 或成员资格后不能再读取服务器历史。

软删除或祖先删除的文档，仅当前工作区 admin/owner 可从“已删除文档”列表发现并查看保留历史。站点管理员不自动获得内容权限，列表只显示保留的当前名称/路径，不代表历史树。P1 不恢复删除。

`ContentService` 历史入口与 `history.py` 负责统一服务规则；`tests/test_content_history.py` 覆盖授权、作用域、可达性、游标和删除边界。已认证原账号的本机稿出口只读自己的缓存，见[本地草稿](05-本地草稿.md)。
