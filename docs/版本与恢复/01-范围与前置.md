# 范围与前置

[索引](README.md)，[行为规范](行为规范.md)，[决策记录](决策记录.md)

P0/P1 实现沿用作品访问根与默认 scope，不新增分支、项目快照、恢复删除或草稿列表。固定迁移链、历史服务、回执、Vue 本机草稿和界面已接线；最终独立审阅和交付状态见[执行记录](执行记录.md)。

数据库 schema 只由 `migrations/versions` 固定迁移定义。`src/storage/migrations.py` 协调新建、真实协议 2 基线核验、升级和只读版本门禁；运行仍用 sqlite3/Repository/UoW，SQLAlchemy 仅在迁移内使用。接管后 Alembic revision 为唯一版本依据，user_version=3 只阻断旧写程序。

显式管理命令是 `python -m src.storage init/backup/upgrade/migrate-legacy`。启动不迁移。协议 2 源库必须核验实际表、约束、外键、部分索引、触发器及数据后才能登记基线；未知结构拒绝。

部署在现有 flock 内停 Compose、核实无运行服务、备份、升级、只读核验再启动。运维须先停止同库外部 CLI、旧 Web、后台写入；脚本只能核实管理的 Compose 服务。迁移失败保持停止；启动后可能已开放写入，不自动恢复旧备份。

真实 SQLite 升级、caller 回滚及失败原子性见 `tests/test_migrations.py`；维护 helper 的本地管理命令检查见 `tests/test_deployment.py`。本地 Docker daemon 权限不足；随后 GitHub Actions 已完成真实镜像构建、smoke 和 test 发布，见[执行记录](执行记录.md)。
