# 保存确认

[索引](README.md)，[行为规范 W01–W09](行为规范.md)，[本地草稿](05-本地草稿.md)

Vue 保存/恢复经 DocumentSession 建立固定操作 ID、基础 revision 和请求 DTO。待确认操作与正文先完成 IndexedDB 事务后发送；后续输入不会修改已捕获请求。服务端同账号同键不同请求返回冲突，同请求重放只返回已存成功结果。

正文、指针和成功回执在同一应用事务提交。无变化也记录回执；记录不含正文，默认保留，不自动过期或 GC。回执 result_revision 与独立读取的当前 head 分开；后续已有新版本时保留本机文字并进入比较。

网络或响应不确定时保留 pending；“查询操作结果”和“重试同一请求”使用固定请求。查询暂不存在不代表未执行，不换新键。首次确定领域失败与此前已有不确定尝试分开处理；后来失去身份或权限不能证明旧请求没有提交。

服务端先验证身份与当前 read 再查询本人回执；已有成功结果即使后来失去 edit 或冻结仍可确认，但不返回历史正文。首次操作额外检查 edit、冻结、基础和恢复来源。

服务入口为 `save_document_operation/restore_document_revision/get_operation_status`；HTTP DTO 和严格错误分类在 `frontend/src/api/client.ts`。证据是 `tests/test_content_operations.py`、`tests/test_server_api.py`、`tests/test_server_transport.py`、`frontend/tests/client.test.ts` 与 `frontend/tests/document-session.test.ts`。旧 CLI/本地 Web 保留无 operation_id 的兼容保存契约。
