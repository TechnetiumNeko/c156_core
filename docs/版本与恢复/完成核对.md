## 跨层和约束核对

- Vue 的新保存、恢复、查询、重试和本地修改通过 DocumentSession，历史只调用 ApiClient；CLI/旧 Web 的无操作键保存契约保留在公共 ContentService。现有角色/access.actions 和服务端统一授权继续生效，组件不另建权限协议。
- 来源、回执和查询的 HTTP 字段/类型/CSRF 由真实 API/transport 用例覆盖；客户端畸形 source_kind 已修复。Bootstrap 的账号/workspace/branch 字段经严格解析后构成草稿键。
- 手动合并只在明确采用时更新本机基础；未处理参考、pending 或冲突不被自动丢弃。恢复独立历史区、保存后重比，以及退出/账号转换的 drain、隐藏、资格释放均经过最终跨层审阅。
- Alembic/SQLAlchemy 仅用于迁移，运行时 Repository 不拥有提交；Docker 白名单包含迁移配置和文件，数据与秘密仍排除。现有自动部署模式、flock、准确 SHA 与不可变镜像 digest 保留。
- 新永久测试对应真实缺陷或关键不变量，沿用已有夹具并观察生产状态/数据库；未新增浏览器平台、点击/填表、测试副本算法或无关容量基准。
- 31 条未因现成代码缩小范围。原生浏览器物理故障、渲染截图/可访问性、prod 发布、灾难恢复演练和大历史容量指标均没有通过声明；这些是已披露的证据限制，不是尚未实施的 P0/P1 必选功能。

全部当前行为的主入口仍是行为规范；后续改变条款时同步相关专题、实现和针对实际风险的证据，不修改旧记录来掩盖差异。
